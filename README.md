## Namensschildgenerator

Ein kleines Werkzeug zum Erstellen von Namensschildern zum Falten – als Tischaufsteller.
Alles läuft in einer einzigen `index.html`, ohne Server und ohne Abhängigkeiten.

### Was es kann
- **A5** (ein Schild) oder **A4** (zwei Schilder zum Auseinanderschneiden), quer oder hoch
- Motivrahmen in vier Stilen, aus 83 an- und abwählbaren Motiven zusammengewürfelt
- Vorder- und Rückseite getrennt beschriften: Schrift, Größe (auch automatisch), Zeilenabstand, Farbe, Ausrichtung, Versalien, Schatten
- Falt- und Schnittkanten sowie der Rahmen um das Textfeld lassen sich abschalten
- Export als **PNG** oder **PDF** (150/300/600 dpi), randlos und in Originalgröße
- Helles und dunkles Design, Rückgängig/Wiederholen, automatisch gesicherter Entwurf

### Druck
Die Seitengröße im Druckdialog wird automatisch auf **genau das gewählte Papier** gesetzt
(`@page { size: <Breite>mm <Höhe>mm; margin: 0 }`) – ohne Ränder und ohne zusätzliche
Rahmen oder Schnittlinien. Die Bildschirmvorschau zeigt das Blatt in Originalgröße, damit
Vorschau, Ausdruck und Export übereinstimmen. Im Druckdialog bitte Skalierung bei 100 %
belassen.
